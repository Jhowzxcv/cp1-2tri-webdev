Estados da aplicação

Toda tela que consome a API implementa os quatro primeiros. Nenhum deles pode ser a ausência de tela.

Carregando

Esqueleto com a forma do resultado esperado — evita salto de layout quando os dados chegam.

Vazio
Nada por aqui ainda Busque uma série e adicione à sua lista para começar a acompanhar.

Nunca uma lista em branco: ícone, o que aconteceu e qual é o próximo passo.

Erro
Não deu para carregar A conexão com o catálogo falhou. Verifique sua internet e tente de novo.

Linguagem comum, sem código de status, e sempre um caminho de saída.

Sem chave de API
Chave da API não configurada Crie um arquivo .env na raiz do projeto com:
VITE_TMDB_API_KEY=sua_chave
Depois reinicie o servidor de desenvolvimento.

Estado de desenvolvimento: falha de configuração não pode virar “erro de rede”.
